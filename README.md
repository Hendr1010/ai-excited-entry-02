"Sky Whale" — a majestic humpback whale soaring through soft white and pale blue clouds, sunlight breaking through, with tiny birds flying nearby for scale.

An entry for the [ai-excited-01 bounty on make.fun](https://make.fun/bounty/ai-excited-01).

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` into the output directory and verifies the copy is byte-identical to the source.

The image is a single 1024×683 JPEG (141,040 bytes) — no build step or extra assets are needed.
